# Word Counter from Text File

## Project Overview

The Word Counter is a Python application that analyzes text files and calculates the total number of words, lines, and characters.

It uses Python file handling techniques to read and process text automatically.

## Features

- Read content from a text file.
- Count total words.
- Count total lines.
- Count total characters.
- Display text statistics.

## Technologies Used

- Python 3
- File Handling
- String Methods
- Built-in Functions

## Project Structure

```text
Word-Counter/
│
├── word_counter.py
├── sample.txt
└── README.md
```

## How to Run

1. Clone the repository.

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder.

```bash
cd Word-Counter
```

3. Add text to `sample.txt`.

4. Run the program.

```bash
python3 word_counter.py
```

## 💻 Sample Output

```text
Words: 10
Lines: 3
Characters: 55
```
